## Naming rule — read this before you write a company name

| Kind of name | Rule |
|---|---|
| Machine **makes** (Union, Realstar, Fulton, Sankosha, Trevil, Speed Queen, Electrolux, Metalprogetti, Bowe, Pilot) | Real make, **invented model number**. Authorised. |
| Utility **retailers** (Momentum Energy, Origin Energy, Coliban Water) | Real, but only ever as a name on a bill. Never author a document that purports to be theirs. |
| Regulators (EPA Victoria, WorkSafe Victoria, Fair Work, ACCC, Consumer Affairs Victoria) | Real. You may write *about* their requirements and cite real instruments. **Never** author a document that purports to have been *issued by* one. |
| Insurer, broker, landlord, chemical supplier, consumables supplier, inspection company, customers | **Fictional.** Invent the name. We do not fabricate a real company's policy schedule, lease or invoice. |

## House voice for these documents

These are meant to survive a dry cleaner reading them over your shoulder.

- **Australian English and Australian law.** Metric. `$` with no currency code.
  Dates as "1 March 2024" in prose, `dd/mm/yyyy` in tables and forms.
- **Write the real thing, not a description of it.** A lease has numbered
  operative clauses, a schedule and an execution block. A manual has a
  specification table, a fault-code table and a service schedule. No
  "[insert clause here]", no "Lorem", no square-bracket placeholders, no
  meta-commentary about being an example.
- **Boring is correct.** Real commercial documents are dry, repetitive and
  specific. Resist making them interesting.
- **Numbers must be internally consistent.** If the rent is $58,400 p.a. then the
  monthly instalment is $4,866.67 and you say so. If a fault code table lists
  E14, some other section must be able to refer to E14 and mean the same thing.
- **Plain text output.** Markdown headings are fine — the app stores the text and
  chunks it on paragraph boundaries — but no HTML, no tables so wide they stop
  being readable as text, and no images.
- **Never** include a real person's name, a real customer, or anything that
  points back at the author's own business.
