## Before you send

- **Site URL.** As things stand the app answers on its github.io address, not on
  hangr.au — the `CNAME` file was deleted in `32b06c6`. If you want them landing
  on `app.hangr.au`, set that up first (see `docs/DNS.md`) and use it in both emails.
- **The password line.** Sending a password in the same email as the link is worth
  avoiding. Consider sending the password by text and replacing that line with
  "I'll text you the password separately."
- **"It will ask you to set your own password."** True if you create each of them a
  login through Users → Add someone. If you're sharing one demo login with a
  password already set, delete that line from both emails.
- **Separate logins.** An email address can only belong to one Hangr business, so
  Catherine and Rita each need their own login on the demo business — the same
  address can't be reused later for a different one.
